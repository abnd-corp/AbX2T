# Contribuer

Ce projet suit la [charte Abnd](https://github.com/abnd-corp/gouvernance/blob/main/CHARTE.md). L'essentiel, pour les humains comme pour les agents :

1. Une issue d'abord, et la PR contient « Closes #N » (R3).
2. Une branche, jamais de push direct sur `main` (R2).
3. Le titre de la PR commence par `feat:`, `fix:`, `chore:`, `docs:`… (R5).
4. Aucune signature d'IA dans les commits, titres et descriptions (R16).
5. Aucun secret dans le code ni dans un message (R9).
6. Une review humaine approuve avant le merge, en squash (R4, R15).

Le détail est dans [CONTRIBUTING.md de la gouvernance](https://github.com/abnd-corp/gouvernance/blob/main/CONTRIBUTING.md). Un écart à la charte se note dans le README du projet (R21).
